# Basys 3 Digital Systems Projects

Introductory Verilog digital systems projects using a Digilent Basys 3 FPGA board and Vivado.

These projects were developed as part of a Digital Systems Design module. 
The aim of this repo is to show basic HDL design, simulation, constraints, and board-level implementation.

## Projects

### `sequential_logic_labs/`

Foundational sequential logic labs covering:

- D flip-flops
- Synchronous and asynchronous reset behaviour
- 8-bit counter design
- Push-button input handling
- Seven-segment display output
- 23-bit LFSR
- Clock division
- LED output multiplexing

This section includes early lab work.

### `mini_alu/`

A 6-bit mini arithmetic logic unit implemented in Verilog.

The ALU supports operations including pass-through, negation, signed comparison, bitwise XNOR, addition, and subtraction. 
The design was tested in Vivado and implemented on the Basys 3 board using switches as inputs and LEDs as outputs.

### `lfsr_sequence_detector/`

A system for detecting a 5-bit codeword in a pseudo-random bitstream generated by an 18-bit LFSR.
The design uses a Moore FSM to detect the target sequence, including overlapping occurrences. A counter tracks detections and displays the result using the Basys 3 seven-segment display.

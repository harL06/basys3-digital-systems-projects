# Sequential Logic Labs

Foundational Verilog designs developed as part of a university Digital Systems Design module.

This section contains earlier lab work covering flip-flops, counters, linear-feedback shift registers, clock scaling, and Basys 3 board integration.

## Overview

The lab work contains three main parts:

- D-type flip-flop experiments
- 8-bit counter system
- 23-bit LFSR system

The aim was to build and test basic sequential logic blocks before using similar ideas in larger FPGA designs.

## Main components

- Positive-edge D flip-flop
- Negative-edge D flip-flop
- Synchronous and asynchronous reset behaviour
- 8-bit counter using D flip-flops
- Push-button increment/decrement controls
- Debounced button inputs
- Seven-segment display output
- 23-bit LFSR
- LFSR max-tick detection
- Bit counter for analysing LFSR output balance
- Clock divider for slower board-level output
- LED output multiplexer
- Basys 3 XDC constraints

## Report

The `docs/` folder contains the original report submitted for the Digital Systems Design module.

The report covers the flip-flop experiments, counter design, LFSR design, simulation results, Basys 3 integration, and physical board demonstrations.
